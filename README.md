# Student Registration with Python and PostgreSQL

A fresh student registration project built from scratch while learning Python, PostgreSQL, and software development fundamentals.

## Technologies

- Python
- PostgreSQL
- Psycopg
- python-dotenv
- Rich

## Current Features

- Connect Python to PostgreSQL
- Load credentials from environment variables
- Read students from the database
- Use a virtual environment
- Track dependencies with `requirements.txt`

## How to Run

```bash
source .venv/bin/activate
python app.py
```
